# SQL Beginner to Advanced — Course Learnings

## 📌 About This Repository

This repository documents my SQL learning journey, from fundamental SQL concepts to advanced querying techniques. It contains practice exercises, queries, and solutions developed during my Data Analytics learning journey.

## 🎯 Learning Objectives

* Strengthen SQL fundamentals.
* Practice filtering, sorting, and aggregating data.
* Understand joins, subqueries, and Common Table Expressions (CTEs).
* Learn window functions and advanced SQL techniques.
* Solve real-world data analysis problems using SQL.

## 🛠️ Tools & Technologies

* **SQL:** MySQL
* **Database Tool:** MySQL Workbench

## 🗄️ Databases Used

This repository includes SQL practice and exercises using the following databases:

| Database                      | Description                           |
| ----------------------------- | ------------------------------------- |
| **AtliQ Hardware (`gdb0041`)** | Sales and business data analysis      |
| **FoodDB (`fooddb`)**         | SQL practice using food-related data  |
| **MoviesDB (`moviesdb`)**     | SQL practice using movie-related data |

**Note:** I used gdb0041 for AtliQ Hardware, which is the database name commonly used in the Codebasics SQL project.


## 📚 Topics Covered

* SQL Basics: SELECT, WHERE, ORDER BY
* Aggregate Functions and GROUP BY
* Joins and Subqueries
* Common Table Expressions (CTEs)
* Window Functions
* Stored Procedures and User-Defined Functions
* Views, Temporary Tables, Triggers, and Events
* Advanced SQL Challenges

## 🚀 Purpose

My goal is to build strong SQL skills and apply them to solve business problems through data analysis.
